# 网页对话与登录

启动 `agent-base serve` 后访问 <http://127.0.0.1:8765/chat>。从左侧 AGENTS 选择 Admin 或已安装的 Repo Agent，发送第一条消息创建对话。Cmd/Ctrl+K 定位 Agent 列表；最近对话可按 Agent、标题筛选。

## 账号登录与会话

从 `/login` 使用管理员分配的账号登录，无自助注册。首次管理员通过本机 `agent-base control init` 初始化。登录后刷新、页面导航、事件流和下载共用浏览器会话。

- 会话有效期 20 分钟，无静默刷新；到期重新登录。
- 退出会撤销服务端会话；Cookie 为 HttpOnly，HTTPS 下带 Secure。
- 全局工作台要求全部全局管理权限；普通用户登录后显示账号信息。
- 没有治理账号时保留本机工作台模式；显式管理 Bearer 配置仍兼容。
- 企业 OSS 目前仅支持已有 token 的身份回查，尚无浏览器 SSO 跳转、回调和统一退出。

账号登录不等于执行数据已经按用户或域隔离。

## 对话操作

| 操作 | 行为 |
| --- | --- |
| 新对话 | 可选择模型与推理强度，已有对话保持原设置 |
| 继续追问 | 复用本对话工作区和 CLI 原生 session |
| 刷新、切换或关闭页面 | 不取消后台生成，重新打开可恢复事件 |
| 停止 | 请求取消当前轮次；以终态为准 |
| 归档/恢复 | 保留历史和目录；活动轮次结束前不能归档 |
| 下载 | 仅下载本会话 `artifacts/` 内文件 |

Enter 发送，Shift+Enter 换行。工具卡片可展开真实参数与结果；原生推理文本不展示。Markdown 禁止原始 HTML，远程图片不自动加载。

网页普通对话不自动执行 entrypoint 或独立 completion 检查；成功标记 `conversation_only`。要交付可验证的后台结果，请让 Admin 提交 Run，见 [运行契约](RepoContract.md)。

## 常见问题

- **刷新后还在运行？** 正常，浏览器只订阅事件；需要停止请点停止按钮。
- **同一对话不能再发？** 每个对话同时只有一个活动轮次；等待结束或先停止。
- **换模型不生效？** 新建对话选择新模型，旧会话保留创建时快照。
- **只有账号页？** 账号尚无全局工作台管理权限，联系管理员分配。
- **会话失败会自动重发吗？** 不会。已收到内容与 session 保留，核对后再决定下一步。

当前连续会话使用 dsh；上传、图片输入、编辑分支与永久删除未提供。接口详情在运行服务的 `/docs`，容量见 [规格速查](Specifications.md)。
